# VoiceLedger — Draft Submission Copy

## Title
VoiceLedger — Talk money. It listens.

## Tagline
A voice-first personal finance ledger for Alexa+: log spending by voice,
get budget alerts and AI insights from a real MCP server.

## Description (one paragraph)
VoiceLedger is a self-hosted MCP server (Streamable HTTP, MCP spec
2025-11-25+) that turns everyday money talk into a living ledger. Say "log
450 rupees for groceries" and the expense is recorded with an
AI-assigned category; ask "what did I spend this week?" or "am I over
budget on dining out?" and you get short, speakable answers — no screens
required. Every spending insight is generated by Amazon Bedrock, with a
fully working offline rule-based fallback so the experience never breaks.
A polished web console simulates the Alexa+ voice experience live against
the real `/mcp` endpoint, so judges can watch actual MCP traffic while
talking to their money.

## How it works
1. **MCP server (Python, official `mcp` SDK):** 9 voice-first tools —
   `log_expense`, `log_income`, `undo_last`, `spend_summary`,
   `budget_status`, `set_budget`, `spending_insights`, `search_expenses`,
   `ping` — served over Streamable HTTP on `/mcp` with bearer-token auth.
2. **Storage:** SQLite ledger (expenses, income, monthly budgets); currency
   defaults to INR and is configurable.
3. **AI (AWS Builder mini challenge):** Amazon Bedrock (`converse` API)
   categorizes each expense and generates 2–3 sentence spending insights
   with one actionable tip. No AWS credentials? A deterministic offline
   categorizer + template insights take over automatically.
4. **Alexa+ experience:** `demo/index.html` is a dark, voice-assistant-style
   console with preset scenario buttons for the 5 demo flows plus a
   free-text box with a keyword intent router — every reply shown is the
   literal text returned by an MCP tool.
5. **Quality bar:** 28 pytest tests (tool logic, budget alerts, undo,
   offline categorizer, full protocol smoke test against a live server),
   MIT licensed, no secrets committed (all config via env vars).
